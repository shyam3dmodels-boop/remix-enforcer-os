1. WHAT RENDER IS DOING & WHY ITS USAGE WAS PREVIOUSLY INVISIBLE
--------------------------------------------------------------------------------
A. What Render is Actively Executing:
   Render (https://encore-secondary-brain-server.onrender.com) hosts the 24/7 central
   cloud nervous system for Secondary Brain 2.0 (`encore-secondary-brain-server`).
   Specifically, Render executes:
   1. Groq Whisper Turbo Audio Pipeline:
      Receives .m4a/.aac audio chunks and ambient recordings streamed from the
      Android phone or Telegram bot, performing sub-second multilingual transcription.
   2. Groq LLaMA 3.3 ReAct AI Intent Engine:
      Parses natural language commands from Telegram and web chat, automatically
      determining hardware tool actions (/locate, /photo, /siren, /mute, /app, /play).
   3. Mem0 Vector & Semantic Knowledge Store:
      Indexes all conversations, notes, user facts, and device state transitions into
      persistent memory with automatic background reflection.
   4. Telegram Bot Two-Way Gateway:
      Maintains long-polling connection to Telegram Bot API, receiving remote
      dispatches and streaming immediate auto-replies back to the sender.
   5. Firebase Firestore Real-Time Mirror:
      Synchronizes telemetry, voice notes, GPS locations, and commands to Firestore
      project `android-1a887` with sub-second WebSocket listeners.

B. Why You Couldn't See Any Use of It Earlier:
   1. Idle Sleep (Spin-Down):
      Render free-tier web services automatically spin down (go into deep sleep)
      after 15 minutes of inactivity. When asleep, incoming requests freeze and take
      50–60 seconds for a "cold start" before returning any data.
   2. Missing UI Visibility:
      The web admin lacked a live container ping monitor, latency gauge, and
      keep-alive heartbeat display, making the cloud backend feel invisible or dead.

C. What We Did to Solve It:
   1. Dedicated Render Cloud Sentinel Card (`RenderCloudSentinelCard.tsx`):
      Added directly to the top of Mission Control in `secondary-brain-admin`:
      • Displays live container status (🟢 LIVE CONTAINER / 🟡 COLD BOOT WAKING).
      • Live Round-Trip Ping Meter (e.g. 112 ms).
      • Manual "Pulse Keep-Alive" button to wake or test container responsiveness.
      • Expandable architectural explainer detailing all active pipelines.
   2. 4-Minute Keep-Alive Daemon:
      Web admin and server now run an automated background pinger every 240 seconds
      (4 minutes) targeting `/api/keepalive`. Because 4m < 15m, Render NEVER goes
      into idle sleep again, guaranteeing sub-second response times 24/7.
   3. Rich `/api/keepalive` Diagnostics:
      Added to `server.py`, returning host details, active service count, and Mem0 status.

4. INSTANT CHAT AUTO-RESPONDER (REPLY TO ANY SENDER IMMEDIATELY)
--------------------------------------------------------------------------------
A. New Architecture in `TelegramC2Manager.kt`:
   • Previously: Commands were only handled for a hardcoded chat ID, and multiple
     updates in a polling batch could lag or drop commands.
   • Newly Added:
     1. Unreplied Command Queue & Message Deduplication:
        Maintains a thread-safe `processedMessageIds` bounded set (size 500)
        storing `"$chatId:$messageId"`.
     2. Universal Sender Acceptance ("No Matter Who Sent It"):
        In `pollTelegramUpdates()`, every valid text update extracts `chatId` and
        `messageId`. Any unreplied message is immediately added to an execution queue.
     3. Immediate Execution & Suitable Action:
        Loops through unreplied commands and immediately invokes `executeCommand(text, botToken, chatId)`.
        The last unreplied command is guaranteed to be acted upon without delay,
        and its action result is replied directly to whatever `chatId` sent the message!
     4. Supported Commands Handled by Auto-Responder:
        • `/start`     -> Welcome card with device connectivity verification
        • `/list`      -> Full command menu with all hardware & sentinel tools
        • `/status`    -> Battery, temperature, network, ringer mode & storage telemetry
        • `/locate`    -> Satellite GPS fix with Google Maps & OpenStreetMap links
        • `/photo`     -> Front or rear camera snapshot delivered directly as photo
        • `/record`    -> Remote microphone ambient audio snippet sent as .m4a audio
        • `/siren`     -> Emergency locator alarm & flashlight strobe
        • `/mute`      -> Force lock all phone streams to 0%
        • `/wipe`      -> Emergency purge of internal audio cache
        • `/app`       -> Open app on phone screen (Spotify, WhatsApp, YouTube, etc.)
        • `/play`      -> Stream media query on Spotify or YouTube
        • `/arp`       -> Inspect `/proc/net/arp` for MAC address duplication
        • `/netscan`   -> Sweep active network interface
        • `/memory`    -> Query Mem0 Secondary Brain status
        • `/summary`   -> End-of-day intelligence and task recap
        • `/tasks`     -> List outstanding Secondary Brain action items
        • `/metrics`   -> Performance and device accountability report
        • `/shield`    -> Toggle stealth focus mode
